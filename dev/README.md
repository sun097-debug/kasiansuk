# เครื่องมือสำหรับพัฒนา (ไม่ใช่ส่วนของแอพ)

ทุกไฟล์ใช้ตัวเลขสมมติเท่านั้น

| ไฟล์ | ทำอะไร | วิธีรัน |
| --- | --- | --- |
| `../tests/test-*.js` | ชุดทดสอบส่วนคำนวณ (54) ช่องกรอก (36) สมุดบันทึก (40) เก็บข้อมูล/สำรอง (22) ภาพตามฤดู (14) | `for t in tests/*.js; do node $t | tail -1; done` |
| `e2e.js` | ทดสอบหน้าจอทั้งเส้นทางในเบราว์เซอร์อัตโนมัติ (จอ iPhone 13 + จอ 320) ถ่ายภาพไว้ที่ `$SHOTS` (ค่าเริ่ม `/tmp/shots`) | เปิดเซิร์ฟเวอร์ `python3 -m http.server 8765` ที่โฟลเดอร์แอพ แล้ว `node dev/e2e.js` |
| `e2e-ledger.js` | ทดสอบหน้าจอสมุดบันทึก 3 หน้า ประวัติ + ตัวกรอง แก้/ลบ สำรอง/กู้คืน จอ 320 กล่องแนะนำไอคอนตามเบราว์เซอร์ (62 ข้อ) | เหมือน e2e |
| `e2e-principal.js` | ทดสอบคำถามเงินต้นแบบใหม่ 0.4.3 + วันที่เติมไว้ 2 วันก่อน 0.4.4 (หน้าเริ่มใช้, บันทึกยอดใหม่, ตอนแก้, ฟอร์มสมุดไม่เปลี่ยน) โดยเลื่อนนาฬิกาของเบราว์เซอร์ (22 ข้อ) | เหมือน e2e |
| `e2e-testing.js` | ทดสอบขั้น Testing: 16 เกณฑ์ตรวจรับ (AC-02, 03, 08, 09, 10, 12, 14, 15, 17, 18, 19, 23, 24, 26, 33, 35) + ตัวเลขเช็กลิสต์ของซัน — นาฬิกาจำลอง 16 ธ.ค. 2569 และ 5 ม.ค. 2570, ตรวจว่าแอพติดต่อแค่ที่อยู่ของตัวเอง (51 ข้อ) | เหมือน e2e |
| `run-all.sh` | **รันทุกชุดในคำสั่งเดียว — ใช้ทุกครั้งก่อนขึ้นรุ่น** (เปิดเซิร์ฟเวอร์เองถ้ายังไม่เปิด) | `bash dev/run-all.sh` |
| `typing.js` | ทดสอบลูกน้ำระหว่างพิมพ์ (พิมพ์ทีละตัว แทรกกลาง ลบ) | เหมือน e2e |
| `make_icons.py` | สร้างไอคอนแอพ (พื้น #CCE7F8 สมุดสีกลาง) | `python3 dev/make_icons.py build '#CCE7F8' icons` |

ต้องมี: Node + `npm i playwright` (ใช้ Chrome) และ Python + Pillow

หมายเหตุ: ผล "กู้คืนแล้วหน้าหลักเท่าเดิม: ต่าง" ใน e2e เป็นเรื่องปกติ — ต่างแค่แถบชวนสำรอง

ไฟล์ข้อมูลทดสอบ (`../test-data/`, ตัวเลขสมมติ): `h10-safari.json`, `h10-homescreen.json` (ชุด T01 สำหรับ H10) · `testing-ledger.json` (ชุด T01 + ยอด 15 มิ.ย. 2568 + สมุดครบทุกประเภท — ใช้กับเช็กลิสต์ขั้น Testing)
