# เกษียณสุข — สมุดบันทึกเงิน กบข. ของคุณ

เว็บแอพบนมือถือสำหรับจดยอดเงิน กบข. แล้วดูกำไรปีนี้แยกจากเงินที่ส่งเข้าไป

- **ไม่ใช่คำแนะนำการลงทุน · ไม่ใช่บริการทางการของ กบข.**
- ข้อมูลอยู่ในเบราว์เซอร์ของเครื่องผู้ใช้เท่านั้น ไม่มีบัญชี ไม่ส่งข้อมูลออกไปที่ใด
- ตัวเลขทั้งหมดในโค้ด ชุดทดสอบ และไฟล์ทดสอบ เป็นตัวเลขสมมติ

สถานะ: รุ่น 0.4.2 — รุ่นทดสอบ (ช่วง B ของขั้น Build: สมุดบันทึก 3 หน้า + แก้ตามที่ลองบน iPhone รอบ 4)

## ไฟล์ในนี้ (อธิบายแบบง่าย)

| ไฟล์ | ทำอะไร |
| --- | --- |
| `index.html` | หน้าเว็บหลัก เปิดแล้วโหลดส่วนอื่นทั้งหมด |
| `css/app.css` | หน้าตา: สี ตัวอักษร รูปทรง — สีทั้งหมดอยู่ในชุดค่ากลางด้านบนไฟล์ |
| `js/calc.js` | ส่วนคำนวณ (ย้ายจากขั้น Calculation สูตรไม่เปลี่ยน) |
| `js/store.js` | เก็บข้อมูลในเครื่อง และไฟล์สำรอง/กู้คืน |
| `js/plans.js` | รายชื่อแผนการลงทุน กบข. (ตารางเดียว แก้ที่นี่ที่เดียว) |
| `js/forms.js` | กติกาตรวจช่องกรอก (รวมสมุดบันทึก) และวันที่ภาษาไทย |
| `js/app.js` | หน้าจอทั้งหมด |
| `fonts/` | ตัวอักษร Mitr และ IBM Plex Sans Thai Looped (สัญญาอนุญาต SIL OFL 1.1 อยู่ในโฟลเดอร์เดียวกัน) |
| `tests/` | ชุดทดสอบ: คำนวณ 54 ข้อ, ช่องกรอก 25 ข้อ, สมุดบันทึก 40 ข้อ, เก็บข้อมูล 15 ข้อ |
| `test-data/` | ไฟล์สำรองตัวเลขสมมติ สำหรับทดสอบบน iPhone |

## รันชุดทดสอบ

```
node tests/test-calc.js
node tests/test-forms.js
node tests/test-store.js
node tests/test-ledger.js
```
